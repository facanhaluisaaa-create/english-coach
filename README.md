# English Mastery — your personal AI English coach

A daily, adaptive English-learning app for one learner who is also an English teacher. Every day it composes a ~20-minute
session from your own memory (recurring weaknesses, due vocabulary, performance trends) and three goals:

1. **CEFR C2 proficiency** — precision, range and naturalness, not ornate vocabulary.
2. **TOEFL iBT® performance** — practice aligned with the 2026 ETS test (12 task types, 1–6 band scores).
3. **Better teaching** — simulated students, explanation practice, mentoring on accuracy, clarity, age-appropriateness and pedagogy.

Built with Next.js 16 (App Router, TypeScript), Tailwind CSS v4 + shadcn/ui, the Anthropic Claude API, Supabase (Postgres + Auth), Zod, Vitest and Playwright. Deploys to Vercel.

## The agent

**English Mastery Coach** is one agent with four skills, expressed as frozen system prompts (`src/lib/ai/prompts.ts`) and structured-output contracts (`src/lib/ai/schemas.ts`):

| Skill | What it does |
|---|---|
| A · C2 Language Coach | Advanced grammar, collocations/idioms, lexical precision, register and pragmatics, pronunciation notes, argumentation. Separates genuine errors from stylistic choices. |
| B · TOEFL Trainer | Original practice in the exact 2026 task formats, timed, rubric-rated, band estimates per section. |
| C · Teaching Mentor | Teaching simulations with a chosen student age/level; evaluates explanations and plans; models a strong alternative. |
| D · Memory & Review Coach | Spaced repetition (SM-2 variant) and active recall over vocabulary and weak concepts; never "masters" anything on one correct answer. |

Each exercise is generated by one structured request (Zod schema → `output_config.format`); every submission is evaluated by another; the evaluation is written back into long-term memory (concepts, error log, vocabulary deck, review log, skill scores). The coach chat streams and sees the same memory.

### Daily session (default, ~20 min)

| Block | Minutes | Content |
|---|---|---|
| Active recall (only when ≥3 items are due) | 3 | Due vocabulary + weak concepts, self-rated, verified by the coach |
| Advanced vocabulary | 5 | 4 C1–C2 items with nuance/collocations; one original sentence each |
| Grammar and precision | 5 | A recurring weakness or an advanced structure: meaning, form, use, register + 4 tasks |
| TOEFL practice | 5 | Rotates Reading → Listening → Speaking → Writing; every 4th day targets your weakest section |
| Teaching challenge | 5 | Explain / correct / plan / answer for a simulated student |

The planner (`src/lib/learning/planner.ts`) is deterministic; block content is generated in parallel.

### Class planning — with you, never without you

**Classes** (`/lessons`) is a co-planning tool for real lessons. The coach cannot prepare a class on its own:

1. **Your brief first.** Class name, ages, CEFR level, size, duration, your aim in your own words, what happened last lesson, your ideas, materials and constraints. The form will not submit without the essentials.
2. **Questions before proposals.** The first coach turn is schema-restricted to questions (`ClarifyTurn` has no plan field), so nothing can be proposed until you have answered.
3. **You hold the pen.** Every later turn may include a *proposal*: a full plan state shown as a diff against your current plan. You apply it, edit it then apply, or discard it. The plan is only ever written by you, directly in the editor or by applying a proposal.
4. **After class.** Save a reflection; it marks the plan as taught, and the coach replies with what to keep, change and try next time. Print view and Markdown export are built in.

### TOEFL iBT (2026) alignment

Verified against the official ETS pages on 6 Nov 2026 (`src/lib/learning/toefl-spec.ts`): Reading 50 items/~30 min (Complete the Words, Read in Daily Life, Read an Academic Passage), Listening 47/~29 (Listen and Choose a Response, Conversation, Announcement, Academic Talk), Writing 12/~23 (Build a Sentence, Write an Email, Write for an Academic Discussion), Speaking 11/~8 (Listen and Repeat, Take an Interview). Sections score 1–6; overall = mean rounded to the nearest half band.

Interface support: reading and writing tasks are on-screen; listening uses the browser's speech synthesis (script shown as fallback); speaking uses the browser's speech recognition (Chrome/Safari) with a typed fallback. Pronunciation cannot be rated from text — the app says so. All scores are **practice estimates, not ETS scores**, and all material is original.

## Setup

1. **Supabase**: create a project, open the SQL editor and run `supabase/migrations/0001_init.sql` then `0002_lesson_plans.sql` (tables, triggers, RLS). In *Authentication → URL configuration* add `http://localhost:3000/auth/confirm` and your production `https://<domain>/auth/confirm` to the redirect allow-list. Email/password and magic-link sign-in are supported.
2. **Anthropic**: create an API key at platform.claude.com.
3. Copy `.env.example` to `.env.local` and fill in the values.
4. Install and run:

```bash
npm install
npm run dev
```

Open http://localhost:3000, sign up, then press **Generate today's session**.

### Environment variables

| Name | Purpose |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase project (anon/publishable key; RLS protects data) |
| `ANTHROPIC_API_KEY` | Claude API key (server only) |
| `ANTHROPIC_MODEL` | Optional, default `claude-opus-5-5` |
| `ANTHROPIC_EFFORT` | Optional `low` / `medium` / `high`, default `medium` (evaluation depth vs. latency) |
| `NEXT_PUBLIC_SITE_URL` | Public URL used in auth emails |

## Deploy to Vercel

1. Import the repository in Vercel; framework preset "Next.js".
2. Add the environment variables above (set `NEXT_PUBLIC_SITE_URL` to the Vercel URL).
3. Session generation and evaluation can take 30–90 s; the relevant routes declare `maxDuration = 300` (Fluid Compute). On the Hobby plan the limit may be lower — lower `ANTHROPIC_EFFORT` to `low` if generation times out.
4. Add the production `/auth/confirm` URL to Supabase's redirect allow-list.
